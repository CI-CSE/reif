# AutoProof tutorial

This tutorial provides a systematic description of how to use AutoProof.
For a shorter introduction refer to the
[AutoProof quick start guide]({% link autoproof/quick-start.md %}).

The tutorial is based on the
[March 2015 PDF version](https://se.inf.ethz.ch/research/autoproof/tutorial/downloads/tutorial.pdf)
of the "AutoProof Tutorial" by the [Chair of Software Engineering](https://se.inf.ethz.ch/)
of [ETH Zurich](https://ethz.ch/).

This guide is work in progress. Sections are being moved from the PDF to
this site and the text is being adapted for the changes in AutoProof
since 2015.
